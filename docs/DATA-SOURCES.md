# Data Sources (Draft)

## Market data (India)
- AMFI NAVAll: official daily NAV file for Indian mutual funds.
- MFAPI: community API built on AMFI NAV data.
- BSE BhavCopy: daily end-of-day equity prices.
- NSE EOD: subscription product for historical end-of-day equity data.

## News and events (future)
- GDELT: global news archive that can be filtered to India for past-only event correlation.

## Notes
- All data shown in the MVP is past-only and for education/research.
- Live refresh and caching will be added after source contracts are finalized.
